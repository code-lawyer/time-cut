# Time-cut privacy

Time-cut processes library files on your computer. Folder and USB imports copy originals to the destination you select. You can also index folders in place. Thumbnails, media indexes, face data, classifications and your edits are stored locally. The managed archive keeps import receipts in its .time-cut directory. The default profile is in %LOCALAPPDATA%\app.timecut.album.

## Optional AI suggestions

Opening a photo or running automatic local classification uses the local library and models. When you explicitly select Codex or Claude Code and click Send preview, Time-cut passes that tool a JPEG image resized to at most 768 pixels on its longest side, encoded without the original capture metadata. The visible content may still identify people, places or documents. The selected tool may send the preview to its provider using your account. The provider and your account settings determine how that request is processed or retained. You decide whether to apply the returned category.

## Maps

Photo details show the saved location locally. Opening the online map in photo details, or viewing the library map, requests tiles for the visible area from the selected provider. Available layers include OpenStreetMap, Esri imagery and Tianditu when configured. Requests disclose your IP address and the requested map area to that provider. Tianditu requests include the token you entered.

## Updates and diagnostics

Time-cut does not collect usage analytics. To update the Windows portable edition, download a new package from the official Releases page linked in About.

## Data you share yourself

External project links open the destination website. If you share an import report or logs with support, review them first. Local reports may contain file paths, device information and details of your media library.
