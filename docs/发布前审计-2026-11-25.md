# Time-cut 公开预览版审计

本轮以 Lap v0.4.1 为上游基线，核对 Time-cut 的源码改动、Windows 成品配置、接收与归档、相册整理、隐私和发行链路。当前测试版本为 `0.1.0-preview.39`。

## 实现与发行

| 发现 | 处理 |
| --- | --- |
| Android 自定义目录中有 `.nomedia` 时，旧版可能先接收该目录的图片，随后才遇到标记。旧盘点也可能继续要求补收已经隐藏的项目。 | 在读取媒体前检查标记，按子目录排除。用新盘点范围迁移旧记录，保留其他待补项与本地完整性校验。复查目录时核对标记。 |
| 切换或重启后，界面与托盘可能继续显示上一次的拔线提示。 | 本次提示与目标和当前单设备接收对应。历史报告保留来源和时间，托盘常驻文字用应用标题。 |
| 照片详情会在打开时加载在线地图。版本说明链接也沿用了上游标签格式。 | 详情先本地显示地点，用户点击后加载在线地图。发布说明链接使用 Time-cut 的标签。Windows 便携包继续使用手动更新。 |
| 旧 XML 解析依赖命中 RUSTSEC-2026-0194，旧 XMP 清理路径可能写回不完整的数据。 | little_exif 改用已修复的 quick-xml 0.42，保留上游代码和许可。XMP 解析错误时中止改写，为嵌套元数据和损坏输入增加回归。 |
| Windows 的旧发行流程无法从实际包逐项找到对应源码和许可。 | 从独立仓库生成带提交与摘要的便携包，附对应源码材料。第三方声明按 Windows 发行物核对。 |

## 功能与验收边界

上一轮在 Galaxy S21 5G 上实际完成了相册内 3,233 项核对、3,200 份不同原件归档与零新增复扫。本轮删除了该次测试在电脑上保存的照片、视频、测试图库和过程数据。新版本使用合成样本和公开测试素材进行桌面和协议回归。保留相册范围内的完整性校验，用户可使用新的空图库进行实机首轮测试。

`.nomedia` 排除依赖手机通过 USB 报告该标记。MTP 暴露的目录清单也受设备、USB 模式和权限影响。本轮没有重新连接用户手机执行首传或实际拔插，也没有完成新版 iPhone 全链路实机验证。预览版按 Windows x64 便携 ZIP 分发，EXE 未签名。

第三方版本告警按实际 Windows 构建依赖和入口复核。依赖锁中的维护状态公告和其他平台公告仍需随版本持续跟踪。主题与人物为辅助整理，可以人工复核和修改。

## 回归验证

- Windows 桌面回归覆盖新图库、导入和复扫去重、原位索引、视频日期归档、主题和人物处理，以及切换和移走图库目录后的恢复。
- 中断恢复用约 403 MB 的合成视频验证，覆盖暂存、恢复后重复扫描和篡改检测。
- 格式兼容性用 HEIC、MOV 和 Nikon RAW 等公开样本验证，覆盖实况照片配对、RAW 方向与预览及导入重复件。
- Windows Shell 验证脚本使用独立合成目录，确认相册外文件和 `.nomedia` 目录都不计入清单。
